# ADR 0002: Apache License 2.0

- Status: Accepted
- Date: 2026-07-31

## Context

The project should support open provider plugins, commercial adoption, and contributions from organizations that may hold relevant patents. MIT is shorter and highly permissive, but it contains no explicit patent grant or patent-termination language.

## Decision

Use Apache License 2.0. It permits commercial use, modification, distribution, and private use while adding an explicit contributor patent license and preserving notices.

## Consequences

The license text and notice obligations are longer than MIT, but provider/plugin implementers and commercial adopters receive clearer patent terms. Contributions must remain compatible with Apache-2.0.
