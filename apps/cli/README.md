# Agent Foreman

Use your smartest AI as the supervisor and your fastest AI as the worker — directly from your coding CLI.

The unscoped npm package named `agent-foreman` currently belongs to an unrelated project. Install this CLI from the repository's locally built tarball by following the cross-platform [source installation instructions](https://github.com/SelahattinSert/agent-foreman#installation).

After installation, run `af settings`, validate the selected worker with `af doctor`, and register the explicitly invoked Codex skill and MCP runtime with `af setup codex`. Normal Codex conversations remain unchanged; Agent Foreman runs only when you invoke `$agent-foreman`.

Agent Foreman requires explicit plan approval before implementation and separate apply approval after deterministic gates and Codex review. See the full documentation at <https://github.com/SelahattinSert/agent-foreman>.

Agent Foreman improves reliability through collaborative planning, deterministic checks, iterative review and explicit human approval. It does not guarantee defect-free output.
