# Agent Foreman

Use your smartest AI as the supervisor and your fastest AI as the worker — directly from your coding CLI.

Install with `pnpm add -g agent-foreman`, configure explicit supervisor and worker models with `af profile create`, validate them with `af doctor`, then run `af install-shim codex`. The installer never overwrites Codex and prints the reversible `PATH` setup.

Agent Foreman requires explicit plan approval before implementation and separate apply approval after deterministic gates and Codex review. See the full documentation at <https://github.com/agent-foreman/agent-foreman>.

Agent Foreman improves reliability through collaborative planning, deterministic checks, iterative review and explicit human approval. It does not guarantee defect-free output.
